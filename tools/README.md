- Wording (Omar, 11 Nov): in Arabic, a medical team is always "فريق طبي" (singular, e.g. "اسأل فريقك الطبي", "لفريقك الطبي", "فريقكن الطبي") and "فرق طبية" (plural, e.g. "في فرق طبية بتسكّرها وفرق طبية بتتركها"). Never bare "فريقك" / "فرق". Applies to stories, carousels, captions and scripts from now on.
- Story languages (Omar, 11 Nov): no translations on stories from now on. Instagram stories are English only, TikTok stories Arabic only.
