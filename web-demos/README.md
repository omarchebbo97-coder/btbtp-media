# Website demos (stg.omarchebbo.com)

Working samples of UI ideas for the website: body-map menu, before/after slider,
heartbeat buttons, share and "Ask me" buttons, story timeline, counters, EN/AR switch.

- Open `index.html` in a browser. Plain HTML, CSS and JS, no build step, no libraries.
- Images in `img/` are small WebP crops of the character masters in `refs/` and `scenes/`.
- Each section has a "For the developer" note on how it works.
- Motion turns off when the device has Reduce Motion on.
