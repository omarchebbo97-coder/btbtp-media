# Website demos (stg.omarchebbo.com)

Working samples of UI ideas for the website: body-map menu, before/after slider,
heartbeat buttons, share and "Ask me" buttons, story timeline, counters, EN/AR switch.

- Open `index.html` in a browser. Plain HTML, CSS and JS, no build step, no libraries.
- Images in `img/` are small WebP crops of the character masters in `refs/` and `scenes/`.
- Each section has a "For the developer" note on how it works.
- Motion turns off when the device has Reduce Motion on.

## prototype/
Full clickable prototype of omarchebbo.com with every change from the review:
hero with photo and count-up numbers, book section with buy-now and first page,
donation tracker, photo pairs with drag sliders, "Start here" chooser, shorts row
with a full-screen viewer, compact blog, story timeline, FAQ with buyer questions,
donor section, one newsletter form, slim footer, book page with Buy now / Add to cart,
shop grid, cart drawer and a sticky buy bar. The toolbar switches between four
palettes taken from the site and the book cover (CSS variables on :root[data-palette]).
Photos and texts come from the staging site; first page, donation numbers, payment
methods and the donor link are placeholders.
